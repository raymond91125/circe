# Indirect connectivity & paths between two cells

Can CIRCE say whether two neurons are connected **indirectly** (through other neurons), and return
the **paths**? Yes — this directory is the worked method, using the graph's own connectivity.

Worked pair: **AWCL** (odorant sensory) → **AVBL** (forward-command interneuron). AWCL makes **no
direct** chemical synapse onto AVBL, but reaches it in **2 hops** through four intermediaries
(AIBL, AIYL, ADLL, AVAL — AIB/AIY are AWC's known first-layer interneurons). Over the combined
**synaptic** graph (chemical + gap junction) it also finds **mixed** routes, e.g.
`AWCL –gap→ ADFL –chem→ AIBL –chem→ AVBL`.

## Contents

| Path | What it is |
|------|------------|
| [`queries/01_reachability.rq`](queries/01_reachability.rq) | *Are they connected indirectly?* — a property-path `ASK` over the reified edge. |
| [`queries/02_two_hop_paths.rq`](queries/02_two_hop_paths.rq) | *What are the paths?* — type-pure 2-hop routes with intermediary + per-hop weight. |
| [`queries/03_strong_two_hop_paths.rq`](queries/03_strong_two_hop_paths.rq) | Same as `02` with a **strength filter** (`HAVING` both hops ≥ 5 contacts) — leaves only AWCL→AIBL→AVBL. |
| `paths.py` | The tool: reachability, shortest path(s), and all simple paths ≤ k hops for any `--type` — a single type, a comma list, or `synaptic` (chemical + gap junction combined) — weight-thresholded, via networkx. |
| `results.json` | `paths.py AWCL AVBL --type synaptic --max-hops 3` output (regenerated by the tool). |

## What SPARQL can and can't do here

Connections are **reified** (a `Connection` node carries `cckg:pre` / `cckg:post` / `connection_type`
/ `weight`), so one hop from a cell to a partner is the path `^cckg:pre/cckg:post`.

- **Reachability** (`01`): `(^cckg:pre/cckg:post)+` answers yes/no at any depth — but a property path
  **cannot constrain `connection_type` mid-path** (the type is on the node, not the stepped edge),
  so it traverses *all* layers, including the ~125k predicted neuropeptide edges. In a connectome
  that makes almost every pair "reachable", so a bare `ASK` is weak evidence.
- **Short explicit paths** (`02`): per-hop joins *can* filter the type (each hop binds its own
  `Connection`) and *do* return the intermediary. Practical to ~3 hops; the join count explodes
  past that.

For **type-pure reachability, the shortest path, arbitrary-length or weight-thresholded paths** —
what a property path can't give — use `paths.py`.

## Four things the method gets right (easy to get wrong)

1. **Choose the traversal deliberately.** `--type synaptic` loads chemical + gap junction into one
   graph (a path may mix both hop types); single types answer channel-specific questions. What's
   meaningless is folding in the *predicted* peptide/monoamine layers — ~125k peptide edges alone
   connect almost everything to everything.
2. **Reachability is nearly always "yes"** in a dense connectome — the informative output is the
   **shortest hop count** and the **paths**, not the yes/no.
3. **Edges are stored per dataset**, so raw rows duplicate once per animal — both the `GROUP BY` in
   `02` and `paths.py` aggregate across datasets by **MAX** weight.
4. **Direction matters.** `chemical` / `neuropeptidergic` / `monoaminergic` are directed (pre→post);
   `gap_junction` and `functional` are symmetric and traversed both ways.

## Reproduce

```
uv run cckg build && uv run cckg export        # -> outputs/connectome.ttl (once)

# SPARQL, against any CIRCE endpoint (e.g. the local circe-sparql service):
#   queries/01_reachability.rq          -> true
#   queries/02_two_hop_paths.rq         -> AIBL / AIYL / ADLL / AVAL
#   queries/03_strong_two_hop_paths.rq  -> AIBL only (both hops >= 5 contacts)

# The tool (networkx is an ad-hoc dep, as in pharynx_communities.py):
uv run --with networkx python analysis/connectivity_paths/paths.py AWCL AVBL --type synaptic
uv run --with networkx python analysis/connectivity_paths/paths.py AWCL AVBL --type chemical
uv run --with networkx python analysis/connectivity_paths/paths.py AWCL AVBL \
    --type chemical,gap_junction --max-hops 3 --min-weight 3 --out analysis/connectivity_paths/results.json
```

`paths.py SOURCE TARGET [--type T] [--max-hops K] [--min-weight W] [--out FILE]` works for any pair.
`--type` takes a single `connection_type`, a comma list, or the alias `synaptic`
(= `chemical,gap_junction`); with several types a path may mix hop types, each labelled with its own.
`--min-weight` drops weak edges: one number for every type, or **per-type** floors like
`chemical=5,gap_junction=2` (weights are different counts per type, so per-type floors are the honest
way to filter a mixed `synaptic` graph). Output is deterministic (edges aggregated by MAX, paths
sorted; independent of `PYTHONHASHSEED`).

# CAN neuron: is it a chemical-transmitting neuron?

A worked CIRCE analysis asking whether the **CAN** pair (canal-associated neurons) actually
sends chemical synapses — combining the CIRCE connectome, CeNGEN scRNA-seq, and reporter
transgenics. Short answer: **no conventional fast chemical transmission** — CAN has zero EM
chemical outputs, lacks `snt-1`/`unc-10`, and is the one neuron missing the pan-neuronal
`rab-3` reporter. It *is* gap-junction coupled and receives input; it is not synapse-free.

**Read the write-up:** [`article.md`](article.md) — question, three lines of evidence, the
reporter-vs-scRNA reconciliation, calibrated confidence, caveats, references.

## Contents

| Path | What it is |
|------|------------|
| [`article.md`](article.md) | The write-up. |
| `can_circe.py` | CIRCE-side facts from `outputs/connectome.json` (connections by type/direction, expression, NT code) → `results.json`. |
| `results.json` | Machine-readable CIRCE-side output (regenerated by the runner). |
| `cengen_can.py` | CAN expression of release-machinery genes from CeNGEN (`snt-1`, `rab-3`, `unc-13`, `snb-1`, `unc-10`, DCV genes). Prints recorded values; `--fetch` re-downloads and recomputes. |

## Reproduce

```
uv run cckg build                                   # -> outputs/connectome.json
uv run python analysis/can_neuron/can_circe.py      # CIRCE side -> results.json

uv run python analysis/can_neuron/cengen_can.py           # recorded CeNGEN values
uv run --with pyreadr --with pandas \
    python analysis/can_neuron/cengen_can.py --fetch       # re-download CeNGEN + recompute
```

`can_circe.py` is deterministic (all collections sorted; independent of `PYTHONHASHSEED`).
`cengen_can.py --fetch` pulls CeNGEN's binarized threshold matrices + TPM table from the
`cengenDataSC` package (needs network); WBGene ids were resolved via mygene.info and are
pinned in the script.
